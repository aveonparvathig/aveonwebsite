## LINK QUALITY QUICK ASSESSMENT

### Is This a Good Link?

**Answer yes to ALL = Excellent Link (Keep!)**
- [ ] Source domain is .edu or .gov (or DA 50+)
- [ ] Source is education/technology related
- [ ] Anchor text is keyword-relevant or branded
- [ ] Link is in main content (not hidden in footer)
- [ ] Source site has good traffic/authority
- [ ] No signs of spam or low-quality content

**Red Flags (Don't Pursue)**
- ✗ Pharmaceutical/gambling/casino anchors
- ✗ Source domain DA < 20
- ✗ Website has 100+ outbound links (link farm)
- ✗ Site not indexed in Google
- ✗ No-follow only links (worth pursuing, but lower value)
- ✗ Multiple links from same low-DA domain

## RESPONSE RATE BENCHMARKS

**When to Follow Up:**
```
Initial Email → Wait 5-7 days (first follow-up if no response)
1st Follow-up → Wait 5-7 days (send alternative angle)
2nd Follow-up → Wait 5-7 days (final attempt)
Move On: If 3 attempts with no response, add to "follow-up in 3 months" list
```

**Expected Response Rates:**
- Cold email outreach: 5-10%
- Personalized outreach (research done): 10-20%
- Warm introductions: 30-50%
- Existing relationships: 50-80%

**Goal:**
- Send 100 emails/month → Get 10-20 responses → Close 2-4 links

## COMMON MISTAKES TO AVOID

**✗ DON'T:**
1. Disavow good links (be very careful)
2. Send generic "Hi Sir/Madam" emails (personalize!)
3. Demand links (offer value instead)
4. Buy links from link farms (Google penalties)
5. Ignore no-follow links (still have value)
6. Focus only on .edu links (diversify sources)
7. Give up after first rejection
8. Forget to follow up
9. Publish content with no link-worthy data
10. Target irrelevant sources (stay focused on education)

**✓ DO:**
1. Triple-check disavow file before submitting
2. Spend 5 minutes personalizing each email
3. Lead with value (free resources, case studies, webinars)
4. Only pursue legitimate link opportunities
5. Track all links (follow and no-follow)
6. Balance .edu/.gov with industry publications
7. Try multiple angles and follow up 2-3 times
8. Set calendar reminders for follow-ups
9. Create assets worth linking to
10. Stay focused on education sector relevance

## SUCCESS INDICATORS (Check Weekly)

**Your links are working if:**
- [ ] New links appear in Google Search Console (2-4 weeks)
- [ ] New links show up in Ahrefs/SEMrush (1-2 weeks)
- [ ] Referring domains count increases (visible in GSC)
- [ ] Organic search traffic begins to grow (lag by 4-8 weeks)
- [ ] Target keywords rank improving slowly (lag by 4-8 weeks)

**WARNING SIGNS:**
- ⚠️ No links appearing in tools after 2 weeks (check if indexed)
- ⚠️ Lots of new spam backlinks (stop whatever attracted them)
- ⚠️ DA still declining (may indicate spam still processing)
- ⚠️ Very high no-follow ratio (diversify link sources)
