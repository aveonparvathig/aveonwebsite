## SECTION 1: BACKLINK AUDIT & CLEANUP

### 1.1 Understanding the Spam Problem

**Current Status:**
- 106 spam backlinks with pharmaceutical anchors ("viagra prices in pakistan", etc.)
- These are toxic and harm domain authority
- Google will penalize if left unaddressed
- Cleanup is CRITICAL before aggressive link building

### 1.2 Step-by-Step Spam Backlink Identification

#### Step 1: Export Current Backlinks
```
1. Go to Google Search Console (https://search.google.com/search-console)
2. Navigate to: Links → External Links
3. Export the CSV file of all linking domains
4. Review "Top linking text" section for spam patterns
```

#### Step 2: Use SEO Tools for Verification
- **Ahrefs:** Links > Backlinks > "Spam score" filter
- **SEMrush:** Backlink Analytics > Filter by "Toxic" score
- **Moz:** Link Research Tools > Flag suspicious profiles
- **Free Alternative:** Use Google Search Console + manual review

#### Step 3: Identify Spam Characteristics
**Red Flags to Look For:**
- Pharmaceutical/adult content anchors
- Gambling, casino, or betting sites
- Payday loan websites
- Weight loss pill sites
- CBD/cannabis product sites
- Completely irrelevant industry links
- Low domain authority sources (<10 DA)
- Links from pages with 100+ outbound links (link farms)
- Links from non-indexed pages

#### Step 4: Create Master Spam Backlinks List
**Format Template:**
```
| Source URL | Domain | Anchor Text | Domain Authority | Status |
|-----------|--------|-------------|------------------|--------|
| example.com/page | example.com | viagra prices | 5 | SPAM |
| casino-site.com | casino-site.com | cheap casino | 8 | SPAM |
```

### 1.3 Creating Google Disavow File

#### Step 1: Prepare Disavow File
Create a text file named `disavow.txt`:

```
# Disavow List for www.aveoninfotech.com
# Generated: October 2026
# Format: domain: (entire domain) or URL: (specific page)

# PHARMACEUTICAL SPAM
domain:pharma-spam-1.com
domain:viagra-prices.com
domain:cheap-pills-online.com
domain:pharmacy-deals.com

# GAMBLING/CASINO SPAM
domain:casino-spam.com
domain:betting-sites.com
domain:poker-online.com

# PAYDAY LOANS/FINANCIAL SPAM
domain:quickloans-spam.com
domain:cashadvance-fast.com

# IRRELEVANT LINK FARMS
domain:linkfarm-1.com
domain:linkfarm-2.com

# SPECIFIC SPAM PAGES (if domain is partially legitimate)
url:example.com/spam-page-1
url:example.com/spam-page-2
```

**Format Rules:**
- One entry per line
- Use `domain:` for entire domains (recommended for spam)
- Use `url:` for specific pages only
- Comments start with `#`
- Plain text only, no formatting

#### Step 2: Submit Disavow File to Google

1. **Log in to Google Search Console**
2. **Select your property:** www.aveoninfotech.com
3. **Navigate:** Links → Disavow links
4. **Click:** "Disavow links"
5. **Upload:** your `disavow.txt` file
6. **Confirm** submission

**Important:** Google will show "Your disavow file has been received" - this is normal. Processing takes 2-4 weeks.

#### Step 3: Document the Process
Create a log file tracking:
```
DATE: October 7, 2026
TOTAL SPAM BACKLINKS IDENTIFIED: 106
DISAVOW FILE SUBMITTED: Yes
GOOGLE SEARCH CONSOLE CONFIRMATION: [Screenshot timestamp]
EXPECTED PROCESSING TIME: 2-4 weeks
NEXT REVIEW DATE: November 7, 2026
```

### 8.2 Quality vs. Quantity Metrics

#### Quality Score Calculation

**For each backlink, calculate quality score:**

```
Quality Score = (DA/100 × 30) + (Relevance × 40) + (Anchor × 20) + (Placement × 10)

WHERE:
- DA = Domain Authority of source (0-30 points)
- Relevance = 0-40 points
  * 40: Education industry related
  * 30: Technology related
  * 20: Business/corporate related
  * 10: General/unrelated
- Anchor = 0-20 points
  * 20: Branded or exact match
  * 15: Keyword/relevant
  * 10: Generic anchor
  * 5: Image/unanchored
- Placement = 0-10 points
  * 10: Homepage or top resource page
  * 7-8: Main content area
  * 5-6: Sidebar/footer
  * 0-4: Low visibility area
```

**Target Distribution:**
- 80+ quality score: 30 links (60%)
- 60-79 quality score: 15 links (30%)
- 40-59 quality score: 5 links (10%)

## SECTION 12: RISK MITIGATION

### Potential Issues & Solutions

#### Issue #1: Low University Response Rates
**Risk:** Universities may ignore outreach  
**Mitigation:**
- Highly personalize emails (mention their specific challenges)
- Start with case study from similar institution
- Offer genuine value (free trial, consultation)
- Multiple contact attempts (email → LinkedIn → phone)
- Use referrals when possible (existing customer introductions)

#### Issue #2: Publication Rejections
**Risk:** Pitched articles may be rejected  
**Mitigation:**
- Have 5-10 different article angles ready
- Adjust based on feedback
- Target lower-DA publications first to build writing history
- Consider paid placement (sponsored content) as backup
- Create guest post opportunities on your own network

#### Issue #3: Low Disavow Effectiveness
**Risk:** Spam links might not impact DA significantly  
**Mitigation:**
- Track domain metrics 4 weeks post-disavow
- If DA doesn't improve, re-evaluate spam assessment
- Consider manual removal requests (contact site directly)
- Focus on building quality links while cleaning

#### Issue #4: Links Slow to Impact DA
**Risk:** New links may take 4-8 weeks to impact Domain Authority  
**Mitigation:**
- Track referring domains immediately (will increase faster than DA)
- Focus on consistent acquisition (compounding effect)
- Ensure links are indexed (check in Ahrefs/GSC)
- Promote links through social media/mentions to speed indexing
- Have patience - DA improvement is lagging indicator

#### Issue #5: New Spam Backlinks
**Risk:** May attract new spam links despite cleanup  
**Mitigation:**
- Set up Google Search Console monitoring
- Monthly manual review of new backlinks
- Quickly disavow any new spam
- Never link to/engage with low-quality sites
- Keep disavow file updated

## APPENDIX B: Link Quality Assessment Rubric

### Scoring Each New Backlink

**Domain Authority (DA):**
- 50+ = 25-30 points
- 40-49 = 20-24 points
- 30-39 = 15-19 points
- 20-29 = 10-14 points
- 10-19 = 5-9 points
- <10 = 0-4 points

**Relevance:**
- Highly relevant (.edu/.gov, education industry) = 35-40 points
- Related (technology, software, business) = 25-34 points
- Tangentially related = 15-24 points
- Not related = 0-14 points

**Link Placement:**
- Homepage = 8-10 points
- Main content (first 100 words) = 6-7 points
- Body content = 4-5 points
- Sidebar/footer = 2-3 points
- Buried/hard to find = 0-1 points

**Anchor Text:**
- Brand + keyword = 18-20 points
- Keyword-rich relevant = 15-17 points
- Natural generic = 12-14 points
- Branded only = 10-11 points
- Image/unanchored = 5-9 points
- Off-topic anchor = 0-4 points
