## HOW TO FIND UNIVERSITY CONTACTS

### Method 1: University Directory Search
```
1. Go to [University Name].edu
2. Search: "[University] directory" or "[University] IT"
3. Find department pages:
   - Information Technology / IT Services
   - Student Administration
   - Admissions / Registrar
   - Campus Operations
4. Look for department contacts section
5. Get email addresses from directory
```

### Method 2: LinkedIn Search
```
1. Go to LinkedIn.com
2. Search: "[University Name] CIO" or "[University] IT Director"
3. Filter by location and current company
4. Look at recent titles and job changes
5. Click profile → "Open to work" or "Message"
6. Extract email if visible, or find via email tools
```

### Method 3: University Press Releases
```
1. Search: "[University] news" or "[University] press release"
2. Look for announcements about:
   - IT initiatives or transformations
   - New student systems
   - Digital transformation
3. Read articles to find quoted names
4. Search those names on LinkedIn + university directory
5. Find email through university email format
```

### Method 4: Email Finding Tools (optional)
- **Hunter.io** (free tier): Find email from domain
- **RocketReach**: Professional email lookup
- **Clearbit**: Company/person data
- **Google Search**: [Name] + [University] + email/contact
